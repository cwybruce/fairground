Fairground is a carnival at dusk in Port Vane: you are a grifter working the midway before closing — lift the prize-till cash, steal the security truck, outrun the police around the Ferris wheel, and vanish through the main gate.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.
